WHERE I PARK — Smart Campus Parking Demo

HOW TO RUN
1. Extract the ZIP folder.
2. Open index.html in Chrome, Edge or another modern browser.
3. Choose Student Portal to make a booking.
4. Switch to Parking Incharge in the left sidebar to see incoming bookings, manage slots and export records.

FEATURES
- Two separate interfaces: Student and Parking Incharge
- Booking captures student name, ID, phone, department, vehicle details, date, duration and chosen slot
- Booking immediately appears in the Incharge dashboard
- A booked slot becomes unavailable and capacity counters update
- Student booking history
- Zone A/B/C availability overview
- Incharge can cancel bookings (cancelled slots become available again)
- Add, activate/deactivate or remove slots
- Search booking ledger and filter by status
- CSV export of booking records
- Responsive layout for mobile and desktop
- Local persistence via browser localStorage

DEMO LIMITATION
This is a front-end prototype. Data is stored in the browser/device that opened the site. It does not provide shared cross-device data, real authentication, server-side access controls or notifications. For a real campus deployment, add a backend/database, secure student/incharge login, institution verification, audit logs, push/email notifications, QR check-in and reservation time expiry.
